# 2026-11-11

## Today's Focus: S3 Presigned URLs — Time-Limited Downloads of Private Objects

## 1. Prepare the CLI and a Dedicated Private Bucket

Create a private S3 bucket and upload a small text file to it. 
The bucket will be used to generate a presigned URL for downloading the file:

```bash
mkdir -p s3-presigned-practice
cd s3-presigned-practice

export AWS_PROFILE=management-admin
export AWS_REGION=us-east-1
export AWS_PAGER=""

aws sso login --profile "$AWS_PROFILE"
aws sts get-caller-identity --profile "$AWS_PROFILE"

LAB_BUCKET="journal-presign-$(python3 -c 'import uuid; print(uuid.uuid4().hex)')"
LAB_KEY="private/config.txt"

printf 'Development configuration for presigned URL practice.\n' > config.txt

aws s3api create-bucket \
  --bucket "$LAB_BUCKET" \
  --region "$AWS_REGION"

aws s3api put-public-access-block \
  --bucket "$LAB_BUCKET" \
  --public-access-block-configuration \
  'BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true'

aws s3api get-public-access-block --bucket "$LAB_BUCKET"

aws s3api put-object \
  --bucket "$LAB_BUCKET" \
  --key "$LAB_KEY" \
  --body config.txt \
  --content-type text/plain \
  --server-side-encryption AES256
```

## 2. Verify That the Ordinary Object URL Is Private

Run

```bash
OBJECT_URL="https://${LAB_BUCKET}.s3.${AWS_REGION}.amazonaws.com/${LAB_KEY}"

curl --silent --show-error \
  --output unsigned-response.xml \
  --write-out 'Unsigned GET HTTP status: %{http_code}\n' \
  "$OBJECT_URL"
```

Expected result: HTTP 403 for the unsigned request in this setup.

## 3. Generate a Five-Minute Download URL

Run

```bash
PRESIGNED_URL="$(aws s3 presign "s3://$LAB_BUCKET/$LAB_KEY" \
  --region "$AWS_REGION" \
  --expires-in 300)"

curl --fail --silent --show-error \
  --output downloaded-config.txt \
  --write-out 'Signed GET HTTP status: %{http_code}\n' \
  "$PRESIGNED_URL"

diff config.txt downloaded-config.txt
```

Expected result: HTTP 200, and no diff output because both files match.

Run the following command to display the presigned URL. 
Then, copy the URL and open it in a private browser window before it 
expires to verify that the file is accessible without signing in to AWS:

```text
printf '%s\n' "$PRESIGNED_URL"
```

## 4. Test Expiration

After more than five minutes have elapsed from URL generation, run the same GET again. Do not generate a replacement URL before this test.

```bash
curl --silent --show-error \
  --output expired-response.xml \
  --write-out 'Expired GET HTTP status: %{http_code}\n' \
  "$PRESIGNED_URL"

cat expired-response.xml
```

Expected result: HTTP 403 with an expiration-related error if the URL expired normally.

| Test                                    | Expected                      |

## 6. Clean Up the Dedicated Lab Resources

This lab does not enable versioning. Delete the single test object, then delete the empty lab bucket:

```bash
aws s3api delete-object --bucket "$LAB_BUCKET" --key "$LAB_KEY"
aws s3api delete-bucket --bucket "$LAB_BUCKET"

unset PRESIGNED_URL OBJECT_URL
```

Successful deletion commands confirm cleanup of the resources created here.
