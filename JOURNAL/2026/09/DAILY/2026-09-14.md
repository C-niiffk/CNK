## 2. Create the Terraform State S3 Bucket

### 2.1 Create S3

Create a unique bucket name

```bash
export BATCH_ACCOUNT_ID="$(aws sts get-caller-identity --query Account --output text)"
export BATCH_STATE_BUCKET="batch-tfstate-${BATCH_ACCOUNT_ID}-${AWS_REGION}"
echo "$BATCH_STATE_BUCKET"
```

Expected result
```text
batch-tfstate-123456789012-us-east-1
```

Create the bucket (for us-east-1)

```bash
aws s3api create-bucket \
  --bucket "$BATCH_STATE_BUCKET"
```

Expected result

```json
{
    "Location": "/batch-tfstate-123456789012-us-east-1"
}
```

### 2.2 Configure S3 Settings

Enable versioning

```bash
aws s3api put-bucket-versioning \
  --bucket "$BATCH_STATE_BUCKET" \
  --versioning-configuration Status=Enabled
```

Expected result: no output and exit code `0`

Block public access

```bash
aws s3api put-public-access-block \
  --bucket "$BATCH_STATE_BUCKET" \
  --public-access-block-configuration \
  'BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true'
```

Expected result: no output and exit code `0`

Enable encryption

```bash
aws s3api put-bucket-encryption \
  --bucket "$BATCH_STATE_BUCKET" \
  --server-side-encryption-configuration \
  '{"Rules":[{"ApplyServerSideEncryptionByDefault":{"SSEAlgorithm":"AES256"}}]}'
```

Expected result: no output and exit code `0`

Verify

```bash
aws s3api get-bucket-versioning --bucket "$BATCH_STATE_BUCKET"
aws s3api get-public-access-block --bucket "$BATCH_STATE_BUCKET"
aws s3api get-bucket-encryption --bucket "$BATCH_STATE_BUCKET"
```

Expected result

- Versioning shows `Status: Enabled`
- Public access block values are `true`
- Encryption shows `SSEAlgorithm: AES256`

## 7. Deploy ECS Services

### 7.1 Enable ECS Services

Change `deploy_services` to `true` in `terraform.tfvars`

```bash
python3 - <<'PY'
from pathlib import Path
import re

p = Path("terraform/terraform.tfvars")
text = p.read_text()
text, count = re.subn(r'(?m)^deploy_services\s*=\s*false\s*$', 'deploy_services = true', text)
if count != 1:
    raise SystemExit("Expected exactly one deploy_services=false entry.")
p.write_text(text)
PY
```

Verify

```bash
grep '^deploy_services' terraform/terraform.tfvars
```

Expected result

```text
deploy_services = true
```

Terraform Plan

```bash
terraform -chdir=terraform plan -out=services.tfplan
```

Expected result

```text
Plan: ... to add, 0 to change, 0 to destroy.
```

Expected new resources

- `aws_ecs_service.app["app1"]`
- `aws_ecs_service.app["app2"]`
- `aws_ecs_service.core["frontend"]`
- `aws_ecs_service.core["backend"]`

Terraform Apply

```bash
terraform -chdir=terraform apply services.tfplan
```

Expected result

```text
Apply complete!
```

### 7.2 Wait for Services Deployment to Complete


```json

  "batch-platform-lab-app1",
  "batch-platform-lab-app2"
]
```

Wait

```bash
terraform -chdir=terraform output -json service_names > /tmp/batch-services.json

python3 - <<'PY'
import json
import os
import subprocess

services = json.load(open("/tmp/batch-services.json"))
subprocess.run(
    ["aws", "ecs", "wait", "services-stable", "--cluster", os.environ["BATCH_CLUSTER"], "--services", *services],
    check=True
)
print("ECS services are stable.")
PY
```

Expected result

```text
ECS services are stable.
```
