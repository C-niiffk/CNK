## Today's Focus: AWS Project

## Project Objective

Build a small batch execution platform to simulate the migration
of an existing VM-based Java platform to AWS.

### The project focuses on:

- Java-based microservices
- Batch job execution
- Agent-based application execution
- AWS ECS Fargate
- Amazon RDS
- Terraform
- High availability across AZs
