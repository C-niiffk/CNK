# 2026-09-13

## Today's Focus: Deploy batch-platform in AWS

## 1. Preparation Before Deployment

### 1.1 Import the Project

Import `batch-platform.zip` in AWS CloudShell

Unzip the project

```bash
unzip batch-platform.zip
```

Check the project

```bash
ls batch-platform
```


Expected result
```text
frontend-service backend-service agent-service application-service
terraform        docs            pom.xml       README.md
```
### 1.2 Tool Requirements

Check the version of tools

```bash
aws --version
terraform version
docker version
docker info #Expected result: Server: Containers:...
jq --version
python3 --version
```

| Tool      | Requirement                 | Instruction                                |
|-----------|-----------------------------|--------------------------------------------|
| AWS CLI   | v2.x                        | Calls AWS APIs from CloudShell or terminal |
| Terraform | `>=1.11.0` and `<2.0.0`     | Must match `terraform/version.tf`          |
| Docker    | Client and daemon must work | Builds four service images                 |
| jq        | 1.6 or later preferred      | Parses Terraform JSON outputs              |
| Python    | 3.9 or later preferred      | Runs helper scripts                        |

### 1.3 Configure AWS Identity and Region

Set the region

```bash
export AWS_REGION=us-east-1
export AWS_DEFAULT_REGION="$AWS_REGION"
export AWS_PAGER=""
```
Check AWS identity

```bash
aws sts get-caller-identity
```
Expected result

```json
{
  "UserID": "...",
  "Account": "...",
  "Arn": "arn:aws:iam::..."
}
```

### 1.4 Check Oracle RDS Engine Version and Instance Class

List available Oracle 19c versions

```bash
aws rds describe-db-engine-versions \
--engine oracle-se2 \
--region us-east-1 \
--query 'DBEngineVersions[?starts_with(EngineVersion, `19.`)].EngineVersion' \
--output text \
| tr '\t' '\n' \
| sort -Vr
```

Expected result

```text
19.0.0.0.ru-2026-07.spb-1.r1
19.0.0.0.ru-2026-07.mrp-2026-07.r1
19.0.0.0.ru-2026-04.spb-1.r1
19.0.0.0.ru-2026-04.rur-2026-04.r1
```

Choose one available version
```bash
export BATCH_ORACLE_VERSION="19.0.0.0.ru-2026-07.mrp-2026-07.r1"
```

Check whether `db.t3.small` is orderable

```bash
aws rds describe-orderable-db-instance-options \
  --engine oracle-se2 \
  --engine-version "$BATCH_ORACLE_VERSION" \
  --license-model license-included \
  --vpc \
  --query "OrderableDBInstanceOptions[?DBInstanceClass=='db.t3.small'].[EngineVersion,DBInstanceClass,MultiAZCapable,StorageType]" \
  --output table
```

Expected result

```text
----------------------------------------------------------------------
|                 DescribeOrderableDBInstanceOptions                 |
+-------------------------------------+--------------+-------+-------+
|  19.0.0.0.ru-2026-07.mrp-2026-07.r1 |  db.t3.small |  True |  gp2  |
|  19.0.0.0.ru-2026-07.mrp-2026-07.r1 |  db.t3.small |  True |  gp3  |
|  19.0.0.0.ru-2026-07.mrp-2026-07.r1 |  db.t3.small |  True |  io1  |
```

## 2. Create the Terraform State S3 Bucket

### 2.1 Create S3

Create a unique bucket name

```bash
export BATCH_ACCOUNT_ID="$(aws sts get-caller-identity --query Account --output text)"
export BATCH_STATE_BUCKET="batch-tfstate-${BATCH_ACCOUNT_ID}-${AWS_REGION}"
echo "$BATCH_STATE_BUCKET"
```

Expected result
```text
batch-tfstate-123456789012-us-east-1
```

Create the bucket (for us-east-1)

```bash
aws s3api create-bucket \
  --bucket "$BATCH_STATE_BUCKET"
```

Expected result

```json
{
    "Location": "/batch-tfstate-123456789012-us-east-1"
}
```

### 2.2 Configure S3 Settings

Enable versioning

```bash
aws s3api put-bucket-versioning \
  --bucket "$BATCH_STATE_BUCKET" \
  --versioning-configuration Status=Enabled
```

Expected result: no output and exit code `0`

Block public access

```bash
aws s3api put-public-access-block \
  --bucket "$BATCH_STATE_BUCKET" \
  --public-access-block-configuration \
  'BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true'
```

Expected result: no output and exit code `0`

Enable encryption

```bash
aws s3api put-bucket-encryption \
  --bucket "$BATCH_STATE_BUCKET" \
  --server-side-encryption-configuration \
  '{"Rules":[{"ApplyServerSideEncryptionByDefault":{"SSEAlgorithm":"AES256"}}]}'
```

Expected result: no output and exit code `0`

Verify

```bash
aws s3api get-bucket-versioning --bucket "$BATCH_STATE_BUCKET"
aws s3api get-public-access-block --bucket "$BATCH_STATE_BUCKET"
aws s3api get-bucket-encryption --bucket "$BATCH_STATE_BUCKET"
```

Expected result

- Versioning shows `Status: Enabled`
- Public access block values are `true`
- Encryption shows `SSEAlgorithm: AES256`
