## Today's Focus: Deploy management-platform in AWS

## 1. Preparation Before Deployment

### 1.1 Import the Project

Import `management-platform.zip` in AWS CloudShell

Unzip the project

```bash
unzip management-platform.zip
```

Check the project

```bash
ls management-platform
```

Expected result
```text
README.md               docs          global-lb     management-plane        platform-common    
application-plane       gateway       grdc          terraform               pom.xml
```
### 1.2 Tool Requirements

Check the version of tools

```bash
aws --version
terraform version
docker version
docker info
docker buildx version
kubectl version --client
helm version
jq --version
python3 --version
session-manager-plugin --version
```

Expected result: every command succeeds; `docker version` includes both Client and Server.

### 1.3 Configure AWS Identity and Region

Set the region:

```bash
export AWS_REGION=us-east-1
export AWS_DEFAULT_REGION="$AWS_REGION"
export AWS_PAGER=""
```
Check AWS identity

```bash
aws sts get-caller-identity
```
Expected result

```json
{
  "UserID": "...",
  "Account": "...",
  "Arn": "arn:aws:iam::..."
}
```

### 1.5 Check Oracle RDS Engine Version and Instance Class

List available Oracle 19c versions

```bash
aws rds describe-db-engine-versions \
--engine oracle-se2 \
--region us-east-1 \
--query 'DBEngineVersions[?starts_with(EngineVersion, `19.`)].EngineVersion' \
--output text \
| tr '\t' '\n' \
| sort -Vr
```

Expected result

```text
19.0.0.0.ru-2026-07.spb-1.r1
19.0.0.0.ru-2026-07.mrp-2026-07.r1
19.0.0.0.ru-2026-04.spb-1.r1
19.0.0.0.ru-2026-04.rur-2026-04.r1
```

Choose one available version
```bash
export BATCH_ORACLE_VERSION="19.0.0.0.ru-2026-07.mrp-2026-07.r1"
```

Check whether `db.t3.small` is orderable

```bash
aws rds describe-orderable-db-instance-options \
  --engine oracle-se2 \
  --engine-version "$BATCH_ORACLE_VERSION" \
  --license-model license-included \
  --vpc \
  --query "OrderableDBInstanceOptions[?DBInstanceClass=='db.t3.small'].[EngineVersion,DBInstanceClass,MultiAZCapable,StorageType]" \
  --output table
```
