## 2. Create the Terraform State S3 Bucket

### 2.1 Create S3

Create a unique bucket name

```bash
export MANAGEMENT_ACCOUNT_ID="$(aws sts get-caller-identity --query Account --output text)"
export MANAGEMENT_STATE_BUCKET="management-tfstate-${MANAGEMENT_ACCOUNT_ID}-${AWS_REGION}"
echo "$MANAGEMENT_STATE_BUCKET"
```

Expected result
```text
management-tfstate-123456789012-us-east-1
```

Create the bucket (for us-east-1)

```bash
aws s3api create-bucket \
  --bucket "$MANAGEMENT_STATE_BUCKET" \
  --region "$AWS_REGION"
```

Expected result

```json
{
    "Location": "/management-tfstate-123456789012-us-east-1",
    "BucketArn": "arn:aws:s3:::management-tfstate-123456789012-us-east-1"
}
```

### 2.2 Configure S3 Settings

Enable versioning

```bash
aws s3api put-bucket-versioning \
  --bucket "$MANAGEMENT_STATE_BUCKET" \
  --versioning-configuration Status=Enabled
```

Expected result: no output and exit code `0`

Block public access

```bash
aws s3api put-public-access-block \
  --bucket "$MANAGEMENT_STATE_BUCKET" \
  --public-access-block-configuration \
  'BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true'
```

Expected result: no output and exit code `0`

Enable encryption

```bash
aws s3api put-bucket-encryption \
  --bucket "$MANAGEMENT_STATE_BUCKET" \
  --server-side-encryption-configuration \
  '{"Rules":[{"ApplyServerSideEncryptionByDefault":{"SSEAlgorithm":"AES256"}}]}'
```

Expected result: no output and exit code `0`

Verify

```bash
aws s3api get-bucket-versioning --bucket "$MANAGEMENT_STATE_BUCKET"
aws s3api get-public-access-block --bucket "$MANAGEMENT_STATE_BUCKET"
aws s3api get-bucket-encryption --bucket "$MANAGEMENT_STATE_BUCKET"
```

Expected result

- Versioning shows `Status: Enabled`
- Public access block values are `true`
- Encryption shows `SSEAlgorithm: AES256`

### 3.2 Create `terraform/terraform.tfvars`

Get public IP for the ALB allowlist

```bash
export MP_CLIENT_IP="$(curl -fsS https://checkip.amazonaws.com | tr -d '\n')"
echo "$MP_CLIENT_IP"
```

Expected result

```text
203.0.113.10
```

Set the actual IAM operator ARN

```bash
export MP_OPERATOR_ARN='arn:aws:iam::...'
```

Create `terraform/terraform.tfvars`
(Refer to `terraform/terraform.tfvars.example`)

```bash
cat > terraform/terraform.tfvars <<EOF
region = "$AWS_REGION"
project = "management-platform"
environment = "lab"
allowed_cidrs = ["${MP_CLIENT_IP}/32"]
operator_arn = "$MP_OPERATOR_ARN"
oracle_engine_version = "$MP_ORACLE_VERSION"
db_instance_class = "db.t3.small"
eks_version = "1.35"
single_nat_gateway = false
protect_data = true
deploy_ec2_apps = true
image_tag = "v1"
# Optional HTTPS certificate in this region; blank enables restricted HTTP lab access.
certificate_arn = ""
public_hostname = ""

# App2: RHEL 9 x86_64, native Java application.

app2_ami_owner = "309956199498"
app2_key_name = "$MP_KEY_NAME"

# Elasticsearch: RHEL 9 x86_64, native RPM/systemd.
es_ami_id = "$MP_RHEL_AMI"
es_ami_owner = "309956199498"
es_instance_type = "t3.medium"
```
